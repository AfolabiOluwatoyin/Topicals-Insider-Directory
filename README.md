# The Niche Layer 

A concept project by Oluwatoyin Afolabi, built after seeing Topicals launch the Insiders directory in Discord.

## The observation

The directory form already asks a smart multiple-choice question about who someone is, options like "passionate about skincare," "go-to voice / tastemaker," or "love creating content." That covers posture and personality well.

What it doesn't ask is what kind of content someone actually makes. That only shows up in one open text box, "tell us about your content style," which is honest and human but completely unstructured. Once there are more than a handful of responses, there's no way to search or filter by content category. Creators who blend categories, for example fashion and skincare together, are invisible to any search even though they describe themselves clearly in their own words.

## What this project does

This is a small working demo, built on invented sample profiles only, no real Topicals community members, that shows what happens if the content-style answers get tagged into a content category automatically, on top of the self-description field that already exists:

- A side by side comparison of one raw, unsearchable content-style response versus that same response tagged into a content
